Por que ITBI

O imposto só é quitado quando a transferência acontece de fato. Portais mostram pedidos; o ITBI mostra acordos.

1

A prefeitura publica

Belo Horizonte abre a base de ITBI quitado: endereço, área, fração adquirida, valor declarado e base de cálculo.

2

Nós normalizamos

Complementos viram uma chave estável — "AP 902", "apto 902" e "902" são a mesma unidade. Linhas duplicadas caem por hash de conteúdo.

3

Você vê a série

Cada unidade ganha uma linha do tempo de quitações, com alertas de cota parcial e área divergente — para você não comparar coisas diferentes.
